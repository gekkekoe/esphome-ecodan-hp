Auto Adaptive
General Settings
Enable AA Control?Master switch for Asgard's Auto-Adaptive flow-temperature algorithm.
Defrost Mitigation?Adjusts Auto-Adaptive behaviour in conditions where ice formation on the outdoor unit is likely, to reduce defrost frequency and its associated temperature dips.
Smart Boost?Temporarily raises the flow-temperature target when the room is stagnating below setpoint, to recover faster than gradual adaptive control alone would.
General Zone Settings
Heating System Type?Your emitter type — underfloor heating, radiators, or a mix. Used to set safe min/max flow-temperature deltas and defrost-recovery timing for the Auto-Adaptive algorithm. The "*" are the lineair curve versions.
Setpoint Bias?A flat offset added to whatever flow temperature Auto-Adaptive calculates. Positive if the room consistently runs cold, negative if it consistently overshoots.
Global Smart Start Temp?Ceiling on the flow temperature for the first command when a cooling cycle starts, so the system doesn't demand a fully-cold flow while the emitter water is still warm from sitting idle. Only applies before the compressor is actively cooling — once it's running, this cap is lifted and the algorithm targets the true calculated flow. Shared across both zones.

Legionella Prevention ▼
Enable?When a Legionella Prevention run starts, the DHW setpoint is raised to the Legionella setpoint below (the current value is stored). When the run finishes, the stored setpoint is restored.
Legionella Setpoint?DHW setpoint applied while a Legionella Prevention run is active. The compressor heats the water up to this setpoint efficiently. Only the part above it is done by the booster element, so setting it as high as your heat pump tolerates to minimize booster element usage.
Stored Setpoint?DHW setpoint stored at the start of a Legionella run. It is restored when the run finishes. —

Power & Modes ▼
Power?Power On / Stand-by
Service Codes?Enable service codes mode to see additional diagnostic sensors (compressor starts, pipe temperatures, super/subcool, fan speed). Turn OFF before manually reading codes from your MRC display. Turn back ON when done. Always return to the MRC main screen before toggling — service codes will not work otherwise.
Holiday Mode?Enables Holiday Mode on the heat pump, overriding normal scheduling.
Server Control ▼
Enable Server Control?Server Control allows you to override the operations.
Prohibit Controls
DHW?Blocks the heat pump from running any DHW cycle, regardless of tank temperature, schedule, or manual triggers, until turned back off.
Z1 Heating?Blocks the heat pump from heating Zone 1, regardless of schedule or Auto-Adaptive, until turned back off.
Z1 Cooling?Blocks the heat pump from cooling Zone 1, regardless of schedule or Auto-Adaptive, until turned back off.
Z2 Heating?Blocks the heat pump from heating Zone 2, regardless of schedule or Auto-Adaptive, until turned back off.
Z2 Cooling?Blocks the heat pump from cooling Zone 2, regardless of schedule or Auto-Adaptive, until turned back off.
Predictive Control ▼
Enable?Keeps the flow-temp target within ~1°C of the actual feed temperature on every reading (below it in heating, above it in cooling) so a drifting feed can't cross the compressor's cut-off and halt it — preventing short cycles.
Short Cycle Lockout ▼
Lockout Status
—
Lockout Strategy?Server ControlEnables Server Control and prohibits the active zone(s)/mode, then restores the prior controller flags afterwards.

Flow ControlPushes the flow setpoint 5°C past the current actual feed temp (colder in cooling, warmer in heating) so the unit self-satisfies and the compressor stops — the water pump keeps circulating. The original flow setpoint is restored afterwards.
Lockout Duration (min)?How long Short Cycle Lockout holds elevated flow temps after triggering, before returning control to normal Auto-Adaptive behaviour. 0 = feature disabled.
Minimum On-Time (min)?How long the compressor must have already been running before Predictive Control or Short Cycle Lockout will act.
