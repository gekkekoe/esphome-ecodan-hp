Which thermostat do you want to use to control your room temperature?
Asgard Virtual Thermostat
Asgard drives the heat pump directly through the R1/R2 relays (IN1/IN6), giving Auto Adaptive full control of the system.
MRC / Wireless Thermostat
The Mitsubishi main display (MRC) or a wireless thermostat (RCx) keeps control of the heat pump, like in a standard installation.
Using the virtual thermostat requires some wiring:
  • Zone 1: connect 2 spare wires from Asgard R1 to IN1 on the FTC board. Set dip-switch SW2-1 to ON.
  • Zone 2: connect 2 spare wires from Asgard R2 to IN6 on the FTC board. Set dip-switch SW3-1 to ON.
  • Migrating from a wireless (CNRF) thermostat? Set dip-switch SW1-8 to OFF.
  • Using the wireless thermostat as temperature source? Keep SW1-8 in the ON position and set on the MRC: Initial settings → Room sensor settings → Room RC zone select to MRC.
  • ⚠ Switch the heat pump power off at the breaker before touching any internal wiring.
The virtual thermostat also needs a room temperature source (REST API / Home Assistant, a DS18B20 or the MRC sensor) — that is configured in the steps that follow.
